    If you are experiencing an error that reads "This mode is unavailable" then it can mean three things,
    (1) your internet is off,
    (2) the date to play the mode has passed,
    (3) a bug has occurred. If so, report it, even if you aren't sure.
    Please note: The halloween mode only lasts until Novemeber 1st, then you will experience this error.

    If you are experiencing an error that reads "Cannot fetch date" then it can mean two things,
    (1) your internet is off,
    (2) a bug has occurred. If so, report it, even if you aren't sure.

    If you are experiencing an error that reads "No Phrases" then it can mean one thing,
    a bug has occurred and JavaScript isn't assigning the phrases properly.

    If you are experiencing an error that reads "Per-gamemode score setup failed: (extra error info)" inside the console then it can mean one thing,
    a bug has occurred when showing the score for the gamemode that you last played.

    If you are experiencing an error that reads "Unable to begin bgm playback" this can only mean one thing,
    a bug has occurred in the proccess of playing the bgm file.



    If the game freezes, check the console and take a screenshot or copy the text into a bug report.
